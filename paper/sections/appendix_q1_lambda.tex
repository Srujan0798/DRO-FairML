\subsection{Q1: Lambda Hyperparameter Ablation (pilot / incomplete)}
\label{app:lambda-ablation}

This appendix records the \emph{status} of Kuldeep's Q1 request
($\lambda_{\mathrm{init}}\times\eta_{\lambda}$ grid), not a second
canonical science table.  The locked claim in the main text is the
fixed-$\tau{=}1$ 540-row grid with defaults
$\lambda_{\mathrm{init}}{=}0.0$, $\eta_{\lambda}{=}5\times10^{-3}$.

\paragraph{What was attempted}
A partial Adult/DP grid over
$\lambda_{\mathrm{init}}\in\{0.0,0.01,0.1\}$ and
$\eta_{\lambda}\in\{0.001,0.005\}$ was run historically and later
interrupted / dropped before a complete, provenance-clean file was
committed.  Early cells that finished near the defaults already matched
canonical DRO DP at $\alpha{=}0.2$ ($\approx0.237$), consistent with the
defaults being a stable operating point rather than a fragile sweet spot.

\paragraph{What is locked (do not overclaim)}
\begin{itemize}
\item Main results use $\lambda_{\mathrm{init}}{=}0.0$,
  $\eta_{\lambda}{=}5\times10^{-3}$, $\lambda_{\max}{=}1.5$.
\item At $\alpha\ge0.3$ on Adult, accuracy falls below the constant-predictor
  baseline ($\approx0.752$) under the locked protocol regardless of the
  limited $\lambda$ pilots we inspected --- high-$\alpha$ is not rescued by
  dual-step tuning alone.
\item A full published $\lambda$ grid would require a fresh, complete run
  with seed-paired provenance; that is optional Wave-1 work, not part of
  the frozen 540-row claim.
\end{itemize}

\paragraph{Recommendation}
Use the locked defaults above for the main protocol.  Treat any
historical $\lambda$-grid numbers outside
\texttt{results/canonical\_tau1.json} as non-canonical.
