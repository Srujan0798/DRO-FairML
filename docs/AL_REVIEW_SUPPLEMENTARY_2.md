## D1. AL gradient derivation and code correctness

**Hand derivation.** For a single constraint `g(θ) ≥ 0` (satisfied when g=0), the augmented Lagrangian penalty is `(μ/2)·g(θ)²`. Its gradient is:

```
∂/∂θ [(μ/2)·g²] = μ · g · ∂g/∂θ
```

**Code check** (`src/training/dro_fair.py:356-363`):

```python
if self.aug_lagrangian_mu > 0:
    mu = self.aug_lagrangian_mu
    if self.use_dp:
        total_loss = total_loss + 0.5 * mu * g_dp * g_dp
    if self.use_if:
        total_loss = total_loss + 0.5 * mu * g_if * g_if
```

PyTorch autograd on `0.5 * mu * g * g` yields `mu * g * dg/dθ` — exactly the hand-derived gradient. The factor of 0.5 cancels with the power rule's 2.

**Verdict: CONFIRMED CORRECT** — no sign error, no double-counting, gradient matches the classical augmented Lagrangian form (Hestenes 1969, Bertsekas 1982).

## D2. g_dp / g_if non-negativity (no max(g,0) needed)

- **g_dp** (`dro_fair.py:271`): `torch.abs(group_rates[1] - group_rates[0])` — absolute value, always ≥ 0. ✓
- **g_if** (`dro_fair.py:283`): `F.relu(torch.abs(h_i - h_j) - edge_dists - self.gamma)` summed with non-negative weights `(p_i + p_j)/2` — relu output ≥ 0, weights ≥ 0 (probability distribution), so g_if ≥ 0. ✓

**Verdict: CONFIRMED CORRECT** — both constraints are non-negative by construction; no `max(g, 0)` clamp is needed. The design document's claim is accurate.

## D6. Adult α=0.2 seed-3 degeneracy

**Observation.** At α=0.2, seed 3 collapses to the constant predictor at both tested μ values:

| μ | seed-3 accuracy | floor | status |
|---|----------------|-------|--------|
| 5 | 0.752128 | 0.752128 | AT FLOOR |
| 20 | 0.752128 | 0.752128 | AT FLOOR |

But seed 3 is **not** degenerate at other α values:
- α=0.0 μ=5: acc=0.8080 (normal)
- α=0.3 μ=5: acc=0.7819 (normal, actually *higher* than other seeds)

The degeneracy is specific to the (seed=3, α=0.2) interaction — likely this seed's train/test split produces a corruption pattern where the AL penalty overwhelms the tilted loss and drives the model to constant-negative prediction.

**Does excluding it change the verdict?**

| test | p-value | significant at α=0.05? |
|------|---------|----------------------|
| μ=5 all 6 seeds | 0.015625 | ✓ |
| μ=5 excl. seed 3 (n=5) | 0.031250 | ✓ |
| μ=20 all 6 seeds | 0.015625 | ✓ |
| μ=20 excl. seed 3 (n=5) | 0.031250 | ✓ |

Excluding seed 3 does **not** change the verdict — AL remains significant at α=0.05 either way.

**Verdict: REAL but CONTAINED** — seed 3 is genuinely degenerate at α=0.2 (reproducible across μ=5 and μ=20), but the overall AL claim survives its exclusion. The memo already discloses this honestly.

Severity: **MEDIUM** — a per-seed collapse is a real failure mode, but it does not invalidate the headline result.

## D7. Leakage check — does AL see anything canonical DRO doesn't?

**Comparison of inputs:**
- Same `get_dataset(name, random_state=seed)` → same X, y, a, X_val, y_val, a_val
- Same attack: `FairnessTargetedPGD` with identical alpha, pgd_steps, attack_k, random_state

- Same optimizer: AdamW, same lr, weight_decay
- Same training loop: `DroFairTrainer.fit()` with identical parameters

**The ONLY difference:** the addition of `0.5 * mu * g_dp * g_dp` (+ same for g_if) to `total_loss` when `mu > 0`. This term is computed from `g_dp` / `g_if`, which are themselves functions of the current model predictions on the same data. No external signal, no oracle, no extra features.

**Code path analysis.** When μ=0: `aug_lagrangian_mu > 0` is False → block skipped → byte-identical computation graph. When μ>0: the added term is a deterministic function of the existing forward pass. No new data flows in.

**Verdict: NO LEAKAGE** — AL sees exactly what canonical DRO sees. The only difference is the quadratic constraint penalty applied to the same losses.

## D8. Additional observations

### D8a. Precision of floor constants (INFO)
The summary reports floors as 0.7521 / 0.7788 / 0.9016 (4 decimals). The exact values are 0.752128, 0.778833, 0.901578. Rounding is correct but the memo would benefit from stating "test-set majority rate, seed-invariant" as provenance.

### D8b. "3/6 seeds at the floor" language (INFO)
As the memo itself notes, this conflates the floor with floor+0.005. Only 1/6 is at the floor itself (seed 3); the others are above floor+0.005. The `DEGEN` flag in the summary correctly uses floor+0.005.

### D8c. μ guard uses `> 0` not `!= 0` (INFO)
`if self.aug_lagrangian_mu > 0` silently treats negative μ as no-op. This is safe (negative μ would reward constraint violation) and the right default.

### D8d. α=0.1 non-significance (INFO)
At Adult α=0.1 μ=5, AL is NOT significantly better than canonical (p=0.8438, only 1/6 seeds better). The pre-registration requires ≥2/4 cells significant per μ arm, and this cell counts against. The summary correctly reports it as non-significant. This is an honest negative — AL is not universally beneficial; its effectiveness depends on corruption level.
